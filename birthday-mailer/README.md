# Birthday Mailer

Automatically sends birthday wishes using GitHub Actions.

## Setup

Clone the repository.

Install dependencies

```
pip install -r requirements.txt
```

Create GitHub Secrets.

Settings

↓

Secrets and Variables

↓

Actions

↓

New Repository Secret

Create two secrets

EMAIL_ADDRESS

EMAIL_PASSWORD

Push the repository.

Done.

GitHub Actions will run automatically every day.

You can also manually run it from the Actions tab.
